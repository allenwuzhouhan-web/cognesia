SCIENTIFIC STATUS

A model with explicit limits.

Cognesia is experimental research software. Executing neural equations does not establish biologically validated vision, learning or behavior. Recorded stability and biological validation failures remain part of the evidence.

API documentation ↗

The example contains placeholders, never your connected key.

# Set these in your own environment:
# COGNESIA_URL=https://your-workspace.example
# COGNESIA_KEY=your-personal-api-key

curl "$COGNESIA_URL/v1/tools" \
  -H "Authorization: Bearer $COGNESIA_KEY"

curl "$COGNESIA_URL/v1/tools/call" \
  -H "Authorization: Bearer $COGNESIA_KEY" \
  -H "Content-Type: application/json" \
  -H "Idempotency-Key: $(uuidgen)" \
  --data '{"name":"cognesia_models","arguments":{}}'
