The workbench

From anatomy to experiment.

01 / Explore

Connectome-based models

Inspect 3D anatomy and source pathways for FlyWire and BANC. Model provenance keeps measured anatomy and inferred relationships distinguishable.

02 / Configure

Controlled experiments

Set visual stimuli, virtual electrodes, chemical fields and timeline interventions. Pause runs and branch supported checkpoints.

03 / Inspect

Recorded model signals

Compare signals and numerical diagnostics, retain source identity and export local sessions for further analysis.

Scientific status

Experimental, with explicit limits.

Cognesia v@@VERSION@@ is an early research software release. Its ability to assemble anatomy and execute equations does not establish biologically validated vision, learning or behavior.

Historical numerical and biological validation failures remain documented. Peripheral dynamics, some source mappings and model parameters include explicit assumptions.

Run locally

Start with the source.

Install from the repository with Python 3.12, acquire and build the initial model inputs, then launch the local viewer. Datasets and saved recordings are downloaded or generated separately. Large models require substantial memory and disk space.
