    Set up GPT-OSS-20B

    Download a GPT-OSS-20B GGUF model and install a current llama.cpp runtime. Choose their local paths below.

    Weights load in the background; then connect above. Unload releases model memory and stops the agent. Submitted Cognesia experiments may continue. Closing this console service also stops the model it launched.

    Or start it in your terminal
    llama-server --model /path/to/gpt-oss-20b.gguf \
  --host 127.0.0.1 --port 8080 \
  --alias gpt-oss-20b --jinja \
  --ctx-size 16384 --parallel 1 --no-webui \
  --cors-origins localhost --no-cors-credentials

    The runtime must preserve GPT-OSS's Harmony template. The connect check verifies a structured tool call before permitting a study.
